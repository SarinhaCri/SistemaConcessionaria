# 🚗 Sistema de Concessionária - Projeto Java

Este projeto foi desenvolvido como parte de uma atividade acadêmica, com o objetivo de praticar os conceitos de **POO (Programação Orientada a Objetos)** em Java. O sistema simula uma concessionária de carros, permitindo o gerenciamento de veículos e passageiros.

---

## Funcionalidades Implementadas

- ✅ Registrar novos carros com placa e quantidade de passageiros
- ✅ Exibir o total de carros criados
- ✅ Calcular o total de passageiros em todos os carros
- ✅ Listar todos os carros cadastrados e suas informações


## Melhorias Adicionais

Além do escopo solicitado na atividade, foram aplicadas boas práticas e recursos modernos da linguagem:

- Uso de `try-with-resources` para o gerenciamento automático do `Scanner`
- Uso do `switch` moderno com `case ->` (Java 14+)
- Campo `placa` definido como `final`, reforçando a imutabilidade
- Organização do código em dois arquivos: `Carro.java` e `Principal.java`
- Comentários explicativos no código para facilitar a leitura



## Tecnologias Utilizadas

- Linguagem: **Java**
- Versão mínima recomendada: **Java 14**
- Editor sugerido: NetBeans, IntelliJ IDEA ou VS Code
